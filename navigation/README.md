# `navigation/` (reserved)

Dart pathfinding logic lives inside the Flutter package under **`flutter_app/lib/screens/astar_pathfinding.dart`** (`AStarPathfinder`).

This top-level **`navigation/`** directory is intentionally **empty aside from this readme** — reserved so a future team can migrate shared Dart-only routing code here as a reusable package **without blocking** syllabus folder expectations.
