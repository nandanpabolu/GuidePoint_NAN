# Scripts

Cross-platform Flutter helpers invoked from repository root unless noted otherwise.

| Script | Purpose |
|--------|---------|
| `run_macos.sh` | `flutter pub get && flutter run -d macos` shortcut for presenters |
| `open_emulator.sh` | Opens chosen Android Emulator AVD helper (inspect file for prerequisites) |

**Python batch scripts:** `models/runGuidePoint.py` lives inside **`models/`** (heavy ML depends on **`requirements.txt`**).
